## 🛠️ Step-by-Step Installation & Deployment Guide

### 📱 1. Android (Termux) Deployment
```bash
# Termux update & package installation
pkg update -y && pkg upgrade -y
pkg install python git libffi openssl -y

# Clone repo
git clone https://github.com/j66320238-crypto/muserbot.git
cd muserbot

# Setup Environment
cp .env.example .env
nano .env   # Apne API_ID, API_HASH aur BOT_TOKEN daalein

# Run Bot
bash start.sh
```

---

### 🖥️ 2. Linux VPS (Ubuntu / Debian) Deployment
```bash
# Update system
sudo apt-get update && sudo apt-get upgrade -y
sudo apt-get install python3 python3-pip python3-venv git curl -y

# Clone repo
git clone https://github.com/j66320238-crypto/muserbot.git
cd muserbot

# Setup Config
cp .env.example .env
nano .env

# Run with Auto-Script
bash start.sh
```

---

### 🐳 3. Docker & Docker Compose Deployment
```bash
# Start container in detached mode
docker compose up -d --build

# View live logs
docker compose logs -f
```

---

### ⚡ 4. Render / Railway / Koyeb / Heroku Deploy
1. **GitHub** pe is repository ko Fork/Push karein.
2. Apne cloud dashboard (Render, Railway, Koyeb, ya Heroku) pe New Web Service create karein.
3. Environment variables me ye daalein:
   - `API_ID`
   - `API_HASH`
   - `BOT_TOKEN`
   - `ADMIN_IDS`
   - `SPECIAL_ADMIN_ID`
   - `BOT_MASTER_PASSWORD`
4. Build command: `pip install -r requirements.txt`
5. Start command: `python3 reuserbot/main.py`
6. Deploy click karein! 🚀

## 🔒 Security & Data Encryption
- **Fernet AES-128-CBC + HMAC-SHA256**: All phone numbers, 2FA passwords, and Pyrogram String Sessions are strictly encrypted before writing to the SQLite database.
- **PBKDF2 Key Derivation**: High iteration count (200,000 iterations) with automated unique cryptographic salt protection.
- **Pure In-Memory Execution**: Worker userbots run completely in RAM with `in_memory=True`, preventing unauthorized disk session extraction.
